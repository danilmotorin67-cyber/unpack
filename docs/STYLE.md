# Стайлгайд

## Разрешение и пиксели
- Внутреннее разрешение **640×360**, растягивается целым множителем
  (×2 = 1280×720, ×3 = 1920×1080). Фильтрация **nearest**, без сглаживания.
- Детализация: **PX = 4/3** пикселя на единицу мира (`tools/iso.py`). Поднять
  детализацию — увеличить PX и разрешение, весь арт перерендерится сам.
- Один пиксель арта = один пиксель вьюпорта, позиции округляются до целых.

## Изометрия
- Проекция **2:1**: экран = ORIGIN + PX·(x − y, (x + y)/2 − z).
  x — вдоль правой стены (на экране вправо-вниз), y — вдоль левой (влево-вниз), z — вверх.
- Комната показана в разрезе: две дальние стены, пол с торцом, как в примере.
- Всё рисует `tools/iso.py`: сцена собирается из коробов, цилиндров и сфер,
  каждый пиксель трассируется, цвет берётся из палитры по грани:
  **верх — светлый, левая грань — средний, правая — тёмный тон**.
- Масштаб: столешница 39 ед. высотой, стена 85, кружка ~8, коробка 22×18×15.
  Предметы ×1.5 к «реальным» пропорциям, чтобы детали читались.

## Палитра и рампы (67 цветов, `tools/palette.py`)
Генератор не даст сохранить спрайт с цветом не из палитры.
Цвета собраны в **рампы**: у каждого материала 4–7 тонов от тени к блику.
Тени уходят в холодный сиреневатый оттенок, блики в тёплый.
Освещение никогда не «перекрашивает» пиксель в чужой цвет: оно только
сдвигает его на ступень по своей рампе (`shift()`).

| Рампа | Тона (тень → блик) |
|---|---|
| Тёмный | `o d m =` |
| Крем (стены, фарфор) | `1 K k C c W` |
| Светлое дерево (пол) | `2 P p F f q Q` |
| Столешница | `3 J j 4` |
| Тёмное дерево | `5 u v w A` |
| Шалфей | `6 H h G g D` |
| Сине-серый | `7 Z z L l I` |
| Металл | `8 x S s M` |
| Мята | `9 T t O` |
| Картон | `+ N n B b U` |
| Терракота | `0 R r i V` |
| Охра | `$ Y y X` |
| Зелень | `% E e a &` |

## Освещение (`tools/iso.py`)
- **Грани**: верх — светлый тон, левая — средний, правая — тёмный.
- **Круглые формы** (цилиндры, сферы) тонируются плавно по нормали вдоль
  рампы; у глянцевых материалов (керамика, металл, стекло) — блик.
- **Падающие тени**: луч к свету (сверху, чуть слева); пиксель в тени — на
  ступень темнее. Тени дают полки на стене, столешницы, мебель на полу.
- **AO (затенение в углах)**: 24 коротких луча по полусфере; в углах, у
  стыков и под предметами — на одну-две ступени темнее.
- **Рёбра**: передняя кромка верхней грани — на ступень светлее; силуэт
  на фоне дальних объектов — на две ступени темнее своего тона.
- **Контур предметов**: сверху — самый тёмный тон своей рампы, снизу и по
  бокам — общий тёмный `o`, чтобы вещь «стояла».
- **Пол**: у каждой доски свой тон, волокна, редкие сучки.

## Правила
- **Свет** сверху-слева (окно на левой стене): передние кромки верхних граней
  подсвечиваются светлым тоном материала, на полу — луч света.
- Мебель и стены спокойные; яркие акценты (терракота, охра, синий) — на вещах.
- Обводка при наведении — `#fbf5e9`, вещь не на месте — `#c8664f`.
