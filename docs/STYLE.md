# Стайлгайд

## Разрешение и пиксели
- Внутреннее разрешение **320×180**, растягивается целым множителем
  (×4 = 1280×720, ×6 = 1920×1080). Фильтрация **nearest**, без сглаживания.
- Один пиксель арта — один пиксель вьюпорта. Без полупикселей и поворотов на
  произвольные углы; позиции округляются до целых.
- Мелкие предметы: от 6 до 20 px. Коробка — 36×26 px.

## Палитра (строго, 28 цветов)
Всё рисуется **только** этими цветами (`tools/palette.py`, проверяется скриптом).
Тёплая, приглушённая, без чистых насыщенных цветов.

## Правила рисования
- **Контур** — `#2e2430` (тёплый тёмно-фиолетовый), не чёрный. У мелких вещей
  контур только снаружи.
- **Свет сверху-слева:** блик — светлый тон группы или `#fbf5e9`, тень — тёмный
  тон группы снизу-справа.
- В одном предмете **не больше 4–5 цветов** (включая контур).
- Фон (стены, пол) всегда светлее и спокойнее предметов, чтобы вещи читались.
- Акценты (терракота, охра, синий) — только на предметах, не на мебели.
