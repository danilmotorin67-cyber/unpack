# Распаковка

Уютная пиксельная игра про переезд в духе Unpacking: распаковываешь коробки и
раскладываешь вещи по местам. Платформа — Windows (Godot 4.3).

Сейчас готов **уровень 1 — кухня**: 3 коробки, 15 предметов, открывающийся
холодильник, проверка «всё ли на своих местах».

## Управление
- **ЛКМ по коробке**: открыть или достать следующую вещь. Пустую коробку кликом можно убрать.
- **Перетащить вещь**: поставить на полку, столешницу, плиту, подоконник или в холодильник.
- **ЛКМ по холодильнику**: открыть или закрыть дверцу.
- **F11**: полноэкранный режим. **Esc**: выход. **R** на финальном экране: начать заново.

## Структура
```
docs/RESEARCH.md      ресерч механик оригинала и что вошло в наш уровень
docs/STYLE.md         стайлгайд: разрешение, палитра, правила рисования
tools/palette.py      палитра (28 цветов), единственный источник цветов
tools/gen_art.py      генератор всего пиксель-арта и шрифта
game/                 проект Godot 4.3
  project.godot       320×180, целочисленное масштабирование, nearest-фильтр
  scenes/main.tscn    главная сцена
  scripts/main.gd     логика уровня: ввод, раскладка, проверка
  scripts/item.gd     предмет
  scripts/box.gd      коробка
  scripts/pixel_sprite.gd  общий спрайт: опора внизу по центру, попиксельный клик, обводка
  scripts/pixel_text.gd    текст пиксельным шрифтом
  scripts/levels/level_01.gd  данные уровня: зоны, предметы, коробки
  shaders/outline.gdshader    обводка при наведении (белая) и ошибке (терракота)
  assets/             сгенерированные PNG
  tests/autoplay.gd   автотест: проходит уровень мышью и делает скриншоты
```

## Как запустить
1. Установить [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (стандартную версию, не .NET).
2. Открыть `game/project.godot` и нажать F5.

## Как собрать .exe
В Godot: Project → Export → Windows Desktop → Export Project (один раз
скачать шаблоны экспорта: Editor → Manage Export Templates).
Или из консоли:
```
godot --headless --path game --export-release "Windows Desktop" ../build/Unpack.exe
```

## Как менять графику
Вся графика генерируется кодом и проверяется на палитру:
```
python3 tools/gen_art.py
```
Нужен Pillow (`pip install pillow`). Предметы — текстовые карты пикселей в
`ITEMS`, фон кухни — функция `kitchen_bg()`.

## Как добавить предмет
1. Нарисовать карту в `ITEMS` (tools/gen_art.py), запустить генератор.
2. Добавить его в `items` и в одну из `boxes` в `scripts/levels/level_01.gd`,
   указать `allowed`, то есть типы мест, куда его правильно ставить.
