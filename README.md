# Распаковка

Уютная изометрическая пиксельная игра про переезд в духе Unpacking: распаковываешь коробки и
раскладываешь вещи по местам. Платформа — Windows (Godot 4.3).

Четыре уровня, по комнате на каждый:
1. **Кухня**: 17 вещей, холодильник открывается.
2. **Ванная**: 14 вещей, зеркальный шкафчик открывается.
3. **Спальня**: 16 вещей, шкаф для одежды открывается.
4. **Гостиная**: 15 вещей, комод открывается, картины, часы и зеркало вешаются на стены.

Вещи на стенах вешаются на любую из двух стен и сами разворачиваются к нужной.

Перед первой комнатой — приветственный монолог с пиксельным портретом:
текст печатается по буквам, мимика меняется по репликам, портрет говорит и
моргает. Реплики — в `game/scripts/intro.gd`.

Игра запускается на весь экран (F11 — окно).

Звуки по материалам (дерево, керамика, стекло, металл, ткань, пластик,
бумага, растения), звуки коробок и дверец, спокойная фоновая музыка.

## Управление
- **ЛКМ по коробке**: открыть или достать следующую вещь. Пустую коробку кликом можно убрать.
- **Перетащить вещь**: поставить на полку, столешницу, плиту, подоконник или в холодильник.
- **ЛКМ по холодильнику**: открыть или закрыть дверцу.
- **Клик или пробел** на экране «комната готова» переводит к следующей комнате.
- **Клик или пробел** в диалоге: допечатать реплику / следующая реплика.
- **M**: выключить или включить музыку. **F11**: окно / полный экран. **Esc**: выход.
- **R** на финальном экране: пройти комнату заново.

```

tools/gen_art.py      точка входа: рендерит комнаты, предметы, коробки, шрифт; пишет art_data.gd

tools/room_*.py       комнаты: мебель, поверхности (ZONES), дверцы (DOORS)
tools/items.py        модели всех предметов (и настенных) и коробки
tools/glyphs.py       карты шрифта и курсоров
tools/gen_sfx.py      синтез звуков и музыки (WAV)

game/                 проект Godot 4.3
  project.godot       640×360, целочисленное масштабирование, nearest-фильтр
  scenes/main.tscn    главная сцена
  scripts/main.gd     логика уровня: ввод, раскладка, проверка
  scripts/item.gd     предмет
  scripts/box.gd      коробка
  scripts/pixel_sprite.gd  общий спрайт: опора внизу по центру, попиксельный клик, обводка
  scripts/pixel_text.gd    текст пиксельным шрифтом
  scripts/iso.gd      проекция мир <-> экран
  scripts/art_data.gd сгенерировано: якоря спрайтов, следы предметов, поверхности
  scripts/sfx.gd      звуки и музыка
  scripts/dialog.gd   диалог: печать по буквам, эмоции, моргание, речь
  scripts/intro.gd    реплики приветственного монолога

  shaders/outline.gdshader    обводка при наведении (белая) и ошибке (терракота)
```

## Как запустить
1. Установить [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (стандартную версию, не .NET).
2. Открыть `game/project.godot` и нажать F5.

## Как собрать .exe
В Godot: Project → Export → Windows Desktop → Export Project (один раз
скачать шаблоны экспорта: Editor → Manage Export Templates).
Или из консоли:
```
godot --headless --path game --export-release "Windows Desktop" ../build/Unpack.exe
```

## Как менять графику
Вся графика генерируется кодом и проверяется на палитру:
```
python3 tools/gen_art.py
```
Нужны Pillow и numpy (`pip install pillow numpy`). Предметы — модели из
примитивов в `ITEMS`, комната — `kitchen_prims()`, поверхности — `ZONES`.

Звуки: `python3 tools/gen_sfx.py` (нужен numpy). Портрет: `python3 tools/portrait.py`.

## Как добавить уровень
1. Создать `tools/room_<имя>.py` по образцу `room_bathroom.py`: `NAME`,
   `prims()`, `DOORS`, `ZONES` (зоны на стенах: `"wall": "L"/"R"`, `u0..u1`,
   `z0..z1`). Добавить модуль в `ROOMS` в `gen_art.py`.
2. Создать `game/scripts/levels/level_0N.gd` с `room`, правилами предметов и
   коробками. Добавить его в `LEVELS` в `game/scripts/main.gd`.
3. Прогнать автотест: он сам проверит, что всё помещается.

## Как добавить предмет
1. Собрать модель из `box`/`cyl`/`sphere` в `ITEMS` (tools/gen_art.py), запустить генератор.
2. Добавить его в `items` и в одну из `boxes` в файле уровня, указать
   `allowed` (типы мест, куда его правильно ставить) и `snd` (материал для звука).
